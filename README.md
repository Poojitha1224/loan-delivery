📌 About the Repository

Welcome to my JavaScript Business Logic Projects repository! 🚀

This repository contains two JavaScript mini-projects developed to demonstrate programming fundamentals, conditional statements, calculations, and real-world business rule implementation.

Each project solves a different business problem using JavaScript variables, arithmetic operations, and if-else statements.

📂 Projects Included

1. 🏦 Banking Loan Eligibility Pre-Screening System

A JavaScript application that performs a preliminary assessment of a customer’s loan eligibility based on predefined banking rules.

Features:

* Collects customer ID, monthly income, requested loan amount, employment type, credit score, and existing EMI.
* Checks eligibility based on credit score and income.
* Classifies customers into Standard, Restricted, or Not Eligible categories.
* Verifies the existing EMI burden against an assumed income limit.
* Displays eligibility results and remarks.

Technologies: JavaScript

2. 🛍️ E-Commerce Order Discount & Delivery System

A JavaScript application that calculates the final payable amount for an online order by applying discounts and delivery charges.

Features:

* Supports Premium and Regular customer categories.
* Applies membership discounts.
* Provides an additional ₹500 discount for orders above ₹5,000.
* Limits the total discount to 20% of the original order amount.
* Calculates delivery charges based on order value and location.
* Displays the final payable amount and order summary.

Technologies: JavaScript

▶️ How to Run the Projects

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure Node.js is installed on your system.
4. Open the terminal in the folder containing the JavaScript file.
5. Run the required project using:

node "Banking Loan Eligibility.js"

For the e-commerce project, run:

node "E-Commerce Order Discount.js"

Note: Use the exact JavaScript filenames in your repository if they are different.
